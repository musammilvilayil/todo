# StudyForge

Native Expo study planner for MERN + Digital Marketing.

**Build:** `SF-GH-20260901`

## Run from Windows to iPhone
1. Install Node.js 22 LTS (recommended).
2. Install Expo Go on the iPhone.
3. Clone/download this repo.
4. Double-click `SETUP-AND-RUN-WINDOWS.bat`.
5. If asked for `@expo/ngrok`, press `Y`.
6. Scan the tunnel QR with Expo Go.

After setup, use `RUN-WINDOWS.bat`.

## Features
- MERN + Digital Marketing schedule
- Study / Light / Off Day
- 5 Namaz + location-based prayer time refresh
- Local notifications
- Protected 10 PM chat/personal time
- Tasks & assessments
- Learning materials
- Focus timer
- Progress dashboard
- Persistent local storage

## Stability
This build deliberately avoids PowerShell setup scripts, expo-font, vector-icons, blur/gradient native modules, npm overrides and `expo install --fix`.
